# Homigrad

Homigrad is a Garry's Mod gamemode with realistic movement, health, and team-based gameplay. It supports multiple sub-modes like TDM, deathmatch, and hide-and-seek.

## Server / Client Installation

Download the repository as a ZIP file and place the `homigrad` folder into your Garry's Mod `addons` directory. If you are running a dedicated server, make sure the `homigrad` gamemode is selected.

## FAQ

### What language is Homigrad in?
It is currently in English.

### Can I use this in Sandbox/TTT/etc?
The Homigrad movement system and weapons are designed for this gamemode and are not intended as a drop-in addon for unrelated gamemodes.

### How can I customise this for my server?
This project is intended to be a reusable codebase. Configuration should be local to your server and not depend on Harrison-specific services or private infrastructure.

### Can I make my own gamemode using this codebase?
Under the MIT License, you are free to do whatever you want with this code. We simply ask that if you have an improvement, that you make a pull request.
